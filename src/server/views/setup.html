One-time Spotify setup

PlaylistPorter needs a Spotify Developer App to import on your behalf. Spotify requires every third-party tool to register one — five-minute setup, free, only you have access.

  1. Open developer.spotify.com/dashboard and sign in.
  2. Click Create app.
  3. Fill in:
    • App name: PlaylistPorter
    • App description: anything (e.g. Personal music import)
    • Redirect URI: paste exactly: {{redirectUri}}
    • Check Web API
  4. Save. Open the app's Settings tab and copy the Client ID and Client Secret below.

Stored locally in data/spotify-state.json (gitignored). Never sent anywhere except spotify.com.
